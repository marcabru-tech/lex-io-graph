# Política de segurança

## Como relatar uma vulnerabilidade

Não abra issue pública. Escreva para **globaldeeptechecosystem@hubstry.dev** com o assunto "Segurança — Lexiograph", descrevendo:

- o que foi encontrado e onde (página, arquivo ou URL);
- como reproduzir;
- o impacto que você identificou.

Também é possível usar o relato privado do GitHub: aba **Security → Report a vulnerability** deste repositório.

## O que esperar

- Confirmação de recebimento em até 5 dias úteis.
- Correção publicada pelo fluxo normal (PR, testes e deploy), com crédito a quem relatou, se desejar.

O Lexiograph é mantido por uma única pessoa; os prazos acima são de melhor esforço.

## Escopo

O app em produção (lexiograph.hubstry.dev), o código deste repositório e o fluxo de dados do Radar Legislativo. Conteúdo jurídico incorreto não é vulnerabilidade de segurança: relate pelo mesmo e-mail, com o assunto "Conteúdo".
